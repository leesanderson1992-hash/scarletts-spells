# Call It To Dinner layout proposals

These are static, 1440 × 900 visual mockups for the **actual ADLE lesson**. No layout has been selected or applied to the activity.

- **Option 1 — Focused stack:** One reading path from explanation through instruction and the cleaver board to a centred confirmation button.
- **Option 2 — Two-card lesson:** Explanation and step list sit side by side, leaving the full width for the cleaver.
- **Option 2 — Dark:** The same two-card layout and copy with dark-theme colours and contrast.
- **Option 3 — Immersive game board:** Compact guidance above a dark board and a fixed-looking confirmation strip.

Each mockup includes the full owner-supplied game explanation, reminder, both yellow-box instructions and success text. Both instructions are shown together for copy review; the live lesson would replace the first with the second after the cut. The images show the same *comma* round after the syllable cut, with the final `a` selected. The mockups omit ADIE and the developer-only editorial warning. All three retain the lesson progress bar, replay, word counter, full-span letter selection, and a confirmation button. The final implementation should support both light and dark themes, keyboard and touch controls, and short desktop viewports.

Run `python3 design/weak-vowel-dinner/generate-mockups.py` to regenerate the SVGs. The PNGs were rendered from those SVGs for review.
