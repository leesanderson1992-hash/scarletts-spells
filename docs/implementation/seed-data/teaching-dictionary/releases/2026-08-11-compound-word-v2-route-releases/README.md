# Compound Word v2 immutable route releases

Environment-neutral publication package for the approved 14-row Compound Word v2 curriculum. It binds one shared structure authority, one span-aware Teaching Dictionary closure, the two existing signed-off teaching-content rows, and two route releases for `compound_word_lab:v2`.

The package is deliberately Production-dark: it contains no activation revision/head and does not alter intake, learning items, assignments, evidence, completion, review scheduling, gates, or learner data.

`carry-forward-audit.json` records why `breakthrough`, `sunshine`, and `weekend` are not silently projected from closed-v1 into the stricter v2 semantic authority.
