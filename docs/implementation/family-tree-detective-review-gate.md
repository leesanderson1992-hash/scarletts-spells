# Family Tree Detective review gate

Family Tree Detective is implemented as a candidate Word Lab activity for the eight weak-vowel micro-skills. The runtime reads `content/secret-life-of-vowels/detective-approved.json`, which still has no rounds pending source binding and release checks. The development preview at `/dev/adle/family-tree-detective` uses candidate target bindings and existing owner-approved British word clips; it creates no learner evidence.

The Google Sheet's **Family Tree Detective review** tab contains one row for each of the 210 existing word–micro-skill pairs. Column J is the existing full target span; K–M are the proposed single vowel tile, zero-based letter index and masked word. H is the chosen stable pronunciation ID; Q–S identify the word audio clip and its approval scope. T is an editorial family candidate, U shows the existing family name, and V holds the owner's family code to keep. Z records a verified published family ID only when the target is an eligible member. AA–AC hold reviewed relatives, relative audio and any justified spelling or morphology explanation. AD and AE hold separate Part 1 and Detective decisions.

At publication, the selected word must match the governed assignment, exact target span, word sense, pronunciation ID, source fingerprint and approved word-recording hash. The family adapter accepts the exact owner-selected key from a pinned, published v1 or v2 Base Family authority only when the target is an eligible member. It does not create phoneme-change mappings or infer that a relative has a clearer vowel. A changed or withdrawn family is omitted from future Detective snapshots while the approved missing-vowel challenge may remain available. Existing snapshots keep their frozen content.

For `D4_SCHWA_FINAL_ER_FINAL`, a separate morphology adapter can make a two-word Detective view when an active approved morphology record, an approved canonical base and the reviewed final target span prove the transformation. It supports a direct suffix addition (`photograph + -er → photographer`, `safe + -r → safer`) or an explicitly reviewed final-`e` omission (`bake + -er → baker`). It rejects a merely coincidental final spelling such as *water*. The preserved base letters are highlighted separately from the target vowel; the final `e` in *safe* can be aligned as a spelling clue, while a suffix vowel added to *photograph* cannot be misrepresented as preserved from the base. A Base Family membership alone does not prove a particular suffix transformation. The relation, approved morphology hash and chosen recordings must be frozen in the assignment snapshot and checked against current sources for new assignments.

The first vowel choice, optional family clues and second choice are guided evidence. `clearer_sound` is the child's observation. Meaningful-part and same-spelling clue controls require reviewed evidence before they are offered. `no_helpful_clue` excludes other clue selections for that relative. These choices and activity completion do not project an independent spelling success; later answer-hidden production remains governed by the existing proficiency rules.

Before live activation, reconcile the sheet with the current governed assignment and Base Family authority, validate source fingerprints and clips, publish approved rows through the content workflow, and run staging completion and repeat-Finish checks.
