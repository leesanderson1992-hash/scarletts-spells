## Scope and verdict

**The Dynamic Prefix `un-` route generated and completed through the ordinary Production UI on a fresh disposable child.** This proves the route's selection, compiled content, activity flow, completion, and review scheduling with a synthetic queue fixture. It does **not** prove the writing-review-to-canonical-intake path: Review Work failed to offer an assignable skill for the saved synthetic writing, and the queue fixture was inserted directly for this bounded route test. Do not count this as end-to-end intake signoff.

## Remaining limitations

1. The parent Review Work skill-option failure and manual-sample issue-save path still prevent this test from proving writing → parent verification → canonical intake → queue. Investigate the catalogue query error/RLS and fix the parent review handoff; use a new sample and confirm an actual linked `parent_verified_spelling_candidate_mappings` source and `adle_learning_item_sources` row before full intake signoff. The `qa:synthetic-*` rows must never be presented as organic child evidence.
2. `daily_assignments.session_completed_at` remains null even on the clean completed assignment. This is a timestamp consistency issue; the completion status, activity events, review bundle and reload are durable.
3. The two disposable Production child profiles and their QA-labelled records remain for audit. They should be archived through the product when no longer needed, not deleted without a retention decision.

This test establishes route behaviour only. It does not measure Supabase egress or response-time improvement.
